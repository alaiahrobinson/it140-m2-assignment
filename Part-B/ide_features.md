## Feature 1 – Highlighting of the syntax

> One aspect that I observed when using the IDE was the highlighting of the syntax. When I entered code to it, it would have the Python keywords, strings, and numbers in assorted colors, so it would be quite easy to read the code and visually see where the different words are. It would also be easier to see if there was a spelling mistake or even a comma error. 

## Feature 2 – Automatic identification and code formatting.

> Second, there is automatic identification and code formatting. In the Python language, indentation shows what statements belong inside the function, loop, or statement. With an IDE, this indentation can be kept consistent as you write about the program. It improves the readability of programs and can also prevent indentation errors that would otherwise crash into a Python program. 

## Feature 3 – Debugging

> Another especially useful function is debugging and running a program in the IDE. This allows the programmer to run their code, examine the output, and check for errors without using another program. The debugging can also be used to track down a problem as it lets the programmer look at the variables and run the program one line at a time.
